# 🚀 Featured Project

## VChat — Realtime Android Messaging Platform

Modern realtime messaging application built with Java and Firebase.

### Core Features
- Realtime messaging
- One-to-one chats
- Group chats
- Friend system
- Typing indicators
- Reply & forward messages
- Pinned messages
- Restriction system
- Hidden chat recovery
- Realtime Firestore synchronization
- Modular architecture
